# Exploratory Data Analysis (EDA) on Retail Sales Data

## Project Overview
This project analyzes a retail sales dataset containing 1,000 transactions to understand sales performance, product category trends, and customer demographics.

## Objective
- Analyze retail sales data using Python.
- Identify the best-performing product category.
- Explore monthly sales trends.
- Understand customer age and gender distribution.
- Check missing values and duplicate records.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset Description
The dataset contains 1,000 transactions and 9 columns, including Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, and Total Amount.

## Key Findings
- Total recorded sales amount: ₹456,000.
- Total transactions: 1,000.
- Average transaction amount: ₹456.
- Average customer age: 41.39 years.
- Electronics recorded the highest sales at ₹156,905.
- Clothing sales totaled ₹155,580.
- Beauty sales totaled ₹143,515.
- Female transactions: 510.
- Male transactions: 490.
- No missing values or duplicate rows were found.
- All dates were successfully converted to the correct date format.

## Visualizations
The project includes:
1. Total Sales by Product Category
2. Monthly Sales Trend
3. Transactions by Gender
4. Customer Age Distribution

## Conclusion
This analysis demonstrates how Python libraries can be used to explore retail sales data and identify useful sales patterns. The findings can help businesses understand product category performance and monitor monthly sales trends.
